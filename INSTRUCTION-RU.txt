ПРОСТАЯ ИНСТРУКЦИЯ: КАК УСТАНОВИТЬ XRAY VPN НА СЕРВЕР

У тебя есть файл:

install-xray-reality-grpc.sh

Его нужно отправить на сервер и запустить.


ЧТО НУЖНО ЗНАТЬ

Перед установкой у тебя должны быть:

1. IP сервера
   Пример: 67.205.190.3

2. Логин
   Обычно: root

3. Пароль от сервера
   Пример: K7!vQ9#rM2@zP6


ШАГ 1. ОТКРЫТЬ ТЕРМИНАЛ НА КОМПЬЮТЕРЕ

На Mac:
Открой приложение Terminal.

На Windows:
Открой PowerShell.


ШАГ 2. ПЕРЕЙТИ В ПАПКУ, ГДЕ ЛЕЖИТ СКРИПТ

Если файл лежит в папке практика на рабочем столе, на Mac напиши:

cd ~/Desktop/практика

Проверь, что файл виден:

ls

В списке должен быть файл:

install-xray-reality-grpc.sh


ШАГ 3. ОТПРАВИТЬ СКРИПТ НА СЕРВЕР

Вместо IP_СЕРВЕРА подставь настоящий IP.

Пример для сервера 67.205.190.3:

scp install-xray-reality-grpc.sh root@67.205.190.3:/root/install-xray-reality-grpc.sh

После этого терминал спросит пароль.
Вставь пароль от сервера и нажми Enter.

ВАЖНО:
Когда вводишь пароль, символы могут не отображаться. Это нормально.


ШАГ 4. ЗАЙТИ НА СЕРВЕР

Напиши:

ssh root@67.205.190.3

Если у тебя другой IP, замени 67.205.190.3 на свой IP.

Снова введи пароль от сервера.

После входа ты окажешься внутри сервера.


ШАГ 5. ЗАПУСТИТЬ УСТАНОВКУ

На сервере напиши:

chmod +x /root/install-xray-reality-grpc.sh

Потом запусти установку.

Для сервера США:

/root/install-xray-reality-grpc.sh 67.205.190.3 "🇺🇸 USA"

Для сервера Германии:

/root/install-xray-reality-grpc.sh 144.31.141.128 "🇩🇪 Germany"

Если у тебя другой IP, замени IP в команде на свой.


ШАГ 6. ДОЖДАТЬСЯ КОНЦА УСТАНОВКИ

Скрипт будет что-то устанавливать.
Нужно просто ждать.

В конце появится строка, которая начинается с:

vless://

Пример:

vless://a05737f5-6652-4366-a724-1efe8698f21e@67.205.190.3:443?...

ЭТО И ЕСТЬ ГОТОВАЯ ССЫЛКА ДЛЯ VPN.

Скопируй всю строку полностью.


ШАГ 7. ДОБАВИТЬ VPN В ПРИЛОЖЕНИЕ

Открой VPN-клиент.

Найди кнопку:

Import

или:

Import from clipboard

или:

Импорт из буфера обмена

Вставь ссылку vless://...

Сохрани профиль.
Включи подключение.


ЕСЛИ НУЖНО ЗАПОЛНИТЬ ВРУЧНУЮ

В клиенте должны быть такие настройки:

Protocol: VLESS
Address: IP сервера
Port: 443
Network: gRPC
Service name: stage
TLS: Reality
Fingerprint: Safari
Server name: www.samsung.com
Flow: пусто
SpiderX: пусто

UUID, Public key и Short ID брать из вывода скрипта.


КАК ПРОВЕРИТЬ, ЧТО НА СЕРВЕРЕ ВСЕ РАБОТАЕТ

На сервере напиши:

systemctl status xray --no-pager

Если видишь:

active (running)

значит Xray запущен.

Проверить порт:

ss -lntp | grep ':443'

Если видишь строку с xray и 443, значит порт работает.


ЕСЛИ ЧТО-ТО НЕ ПОЛУЧИЛОСЬ

1. Если не входит по SSH:
Проверь IP, логин и пароль.

2. Если пишет Permission denied:
Пароль неверный или вход не под root.

3. Если VPN не подключается:
Проверь в клиенте:
- Network именно gRPC
- Service name именно stage
- TLS именно Reality
- Fingerprint именно Safari
- Server name именно www.samsung.com
- Flow пустой

4. Если надо заново создать ссылку:
Просто запусти скрипт еще раз:

/root/install-xray-reality-grpc.sh IP_СЕРВЕРА "🇺🇸 USA"

Старая ссылка после этого уже не нужна, используй новую.


САМЫЙ КОРОТКИЙ ПРИМЕР ДЛЯ США

На компьютере:

cd ~/Desktop/практика
scp install-xray-reality-grpc.sh root@67.205.190.3:/root/install-xray-reality-grpc.sh
ssh root@67.205.190.3

На сервере:

chmod +x /root/install-xray-reality-grpc.sh
/root/install-xray-reality-grpc.sh 67.205.190.3 "🇺🇸 USA"

Потом скопировать строку vless://... и импортировать в приложение.


УСТАНОВКА С ТЕЛЕФОНА

Если компьютера нет, VPN можно поставить прямо с телефона.

На телефоне понадобится два приложения:

1. SSH-приложение для входа на сервер
   iPhone: Termius
   Android: Termius или JuiceSSH

2. VPN-клиент для VLESS/Xray
   iPhone: Streisand, FoXray, V2Box или другое приложение с VLESS Reality
   Android: v2rayNG или другое приложение с VLESS Reality


ВАРИАНТ С ТЕЛЕФОНА ЧЕРЕЗ TERMIUS

ШАГ 1. Установить Termius

Открой App Store или Google Play.
Найди Termius.
Установи приложение.


ШАГ 2. Добавить сервер в Termius

Открой Termius.
Нажми New Host или плюс.

Заполни:

Alias: любое название, например USA Server
Host: IP сервера
Port: 22
Username: root
Password: пароль от сервера

Пример:

Host: 67.205.190.3
Port: 22
Username: root
Password: пароль сервера

Сохрани сервер.


ШАГ 3. Подключиться к серверу

Нажми на созданный сервер.

Если появится вопрос про fingerprint/key, нажми:

Continue

или:

Accept

После этого откроется черный экран терминала.
Это значит, что ты внутри сервера.


ШАГ 4. Создать файл скрипта на сервере

В Termius вставь команду:

nano install-xray-reality-grpc.sh

Откроется редактор nano.

Теперь нужно вставить текст скрипта install-xray-reality-grpc.sh.

Если текст скрипта у тебя открыт в заметках или файле:
- выдели весь текст;
- скопируй;
- вернись в Termius;
- вставь в nano.

ВАЖНО:
Вставка может занять несколько секунд. Подожди, пока весь текст появится.


ШАГ 5. Сохранить файл в nano

В Termius внизу обычно есть дополнительная клавиатура с кнопкой Ctrl.

Нужно нажать:

Ctrl + O

Потом:

Enter

Потом выйти:

Ctrl + X

Если не видишь Ctrl:
- открой дополнительную клавиатуру Termius;
- найди кнопку Ctrl;
- или нажми кнопку Keyboard / Special keys.


ШАГ 6. Запустить установку

После выхода из nano ты снова увидишь командную строку сервера.

Напиши:

chmod +x install-xray-reality-grpc.sh

Потом запусти скрипт.

Для США:

./install-xray-reality-grpc.sh IP_СЕРВЕРА "🇺🇸 USA"

Пример:

./install-xray-reality-grpc.sh 67.205.190.3 "🇺🇸 USA"

Для Германии:

./install-xray-reality-grpc.sh IP_СЕРВЕРА "🇩🇪 Germany"

Пример:

./install-xray-reality-grpc.sh 144.31.141.128 "🇩🇪 Germany"


ШАГ 7. Дождаться конца установки

Скрипт начнет установку.
На экране будет много текста.
Ничего нажимать не нужно.

В конце появится строка:

vless://...

Скопируй всю строку полностью.

ВАЖНО:
Нужно скопировать именно всю ссылку, начиная с vless:// и до самого конца.


ШАГ 8. Импортировать ссылку в VPN-клиент

Открой VPN-клиент.

Найди кнопку:

Import from clipboard

или:

Import URL

или:

Импорт из буфера обмена

Если такой кнопки нет:
- нажми плюс;
- выбери Import;
- вставь ссылку vless:// вручную.

Сохрани профиль.
Включи подключение.


ЕСЛИ С ТЕЛЕФОНА НЕ ПОЛУЧАЕТСЯ ВСТАВИТЬ СКРИПТ

Можно сделать проще:

1. Открой файл install-xray-reality-grpc.sh на компьютере.
2. Скопируй весь текст.
3. Отправь себе в Telegram / WhatsApp / Заметки.
4. Открой этот текст на телефоне.
5. Скопируй весь текст с телефона.
6. Вставь в Termius после команды:

nano install-xray-reality-grpc.sh


КАК ПОНЯТЬ, ЧТО ВСЕ УСТАНОВИЛОСЬ

На сервере в Termius напиши:

systemctl status xray --no-pager

Если видишь:

active (running)

значит VPN работает.

Проверить порт:

ss -lntp | grep ':443'

Если видишь строку с xray и 443, значит сервер слушает VPN-порт.


ЧАСТЫЕ ПРОБЛЕМЫ НА ТЕЛЕФОНЕ

Проблема: пароль вводится, но его не видно.

Это нормально. В SSH пароли обычно не показываются.
Просто введи пароль и нажми Enter.

Проблема: Permission denied.

Значит неверный пароль, неверный логин или вход root отключен.
Проверь данные сервера.

Проблема: в nano не получается сохранить.

Нужно:

Ctrl + O
Enter
Ctrl + X

Проблема: VPN-клиент не подключается.

Проверь настройки:

Network: gRPC
Service name: stage
TLS: Reality
Fingerprint: Safari
Server name: www.samsung.com
Flow: пусто

Проблема: ссылка vless:// не копируется целиком.

Попробуй выделить строку длинным нажатием.
Если строка переносится на несколько строк, копировать все равно нужно от vless:// до самого конца.
